如果你是研究生、博士、青椒，或任何需要「读文献、写综述」的人，我做了一件可能帮你省下几百个小时的事：

**把 GitHub 上最强的 70+ 个 AI 文献综述工具，按「你要干什么」分成了 11 类，整理成了一个开源清单。**

👉 仓库地址：`github.com/brycewang-stanford/lit-review-agent-tools`（中英双语，CC0 协议，欢迎 Star）

不卖课、不恰饭、不塞私货。就是一份能让你「带着需求来，拿着工具走」的导航。

## 二、为什么要做这个清单？

文献综述是科研里最脏最累的活：检索 → 去重 → 精读 → 主题归纳 → 引用核查……一篇像样的综述，光是筛摘要就能筛到怀疑人生。

这两年 AI 工具井喷，能自动化其中某些（甚至全部）步骤。但问题是：

- **散**：好东西全埋在 GitHub 各个角落，不搜到关键词根本发现不了；
- **杂**：从 39k star 的成熟框架到 20 star 的玩具，混在一起，质量参差；
- **乱**：命名一个比一个玄乎，`deep-research`、`AI-Scientist`、`storm`……到底哪个适合我？

所以我干脆按**使用场景**把它们全部归类，并且：

1. 每个项目的 Star 数都用 **GitHub API 校对过**（还挂了个 Action 每周自动刷新，不会过期）；
2. 只收**开源、在维护、和文献综述强相关**的项目；闭源商业工具单列一节做参考；
3. 配了一个 **「30 秒选型」** 和 **决策表**，你对着自己的需求扫一眼就知道该用哪个。

---

## 三、11 个分类，覆盖文献工作全流程

我把工具分成了这几类，挑几个「镇场子」的说：

### 🌟 综合研究智能体与技能（Claude Code / Codex）
- **academic-research-skills**（~39.5k⭐）—— 本领域最火的项目。一套 Claude Code 技能，10 阶段流水线：研究 → 写作 → 评审 → 修订 → 定稿，内置引用「诚信门」，跨 Semantic Scholar + OpenAlex + Crossref 三源校验。理念很戳我：**「AI 是副驾，不是主驾」**。

### 🔎 深度研究与自动综述生成
- **STORM**（斯坦福，~30k⭐）—— 输入一个主题，自动检索并生成维基百科式长文，带引用。还有对话版 Co-STORM。
- **GPT Researcher**（~28k⭐）—— 通用型自主调研智能体，给个题目就给你带引用的报告。

### 🧪 自主科研：从想法到论文
- **AI-Scientist / v2**（Sakana AI）—— 野心最大的一类：文献调研 + 提假设 + 跑实验 + 写作 + 自评审，端到端全自动。

### 📚 文献问答与 RAG
- **PaperQA2**（FutureHouse）—— 对一堆 PDF 做问答，**回答必带引用**，号称文献检索能力超人。

### 🧮 系统综述与筛选（PRISMA）
- **ASReview** —— 主动学习筛摘要，几千条摘要的筛选时间能砍掉一大半，循证医学圈的老朋友。

### 📄 PDF → 结构化数据抽取（隐形基建）
- **MinerU**（~76k⭐）/ **Docling**（IBM，~64k⭐）/ **marker** —— 把 PDF 变成干净的 Markdown 喂给大模型。这一步做不好，后面全是垃圾进垃圾出。

### 🔌 MCP 服务器
- **paper-search-mcp / zotero-mcp** —— 把 arXiv、PubMed、Zotero 直接接进 Claude / Cursor，让你的 AI 客户端长出「文献手脚」。

另外还有 **🗂️ Zotero/Obsidian 集成、🕸️ 引文图谱与 API 客户端、✍️ 写作与同行评审助手、📖 精选清单** 等好几类，篇幅所限就不展开了，仓库里全有。

## 四、怎么用这个清单？（30 秒选型）

```
我用 Claude Code，想要「研究→论文」端到端  ─▶ academic-research-skills
我想让 AI 自动调研一个主题并出带引用报告  ─▶ GPT Researcher / STORM
我想全自动「从想法到可投稿论文」          ─▶ AI-Scientist-v2
我要对一堆 PDF 做带引用的问答            ─▶ PaperQA2
我在做严谨 PRISMA 系统综述              ─▶ ASReview
我要把 PDF 变干净 Markdown 喂给 LLM     ─▶ MinerU / Docling
我想把文献能力接进 Claude / Cursor       ─▶ paper-search-mcp / zotero-mcp
```
