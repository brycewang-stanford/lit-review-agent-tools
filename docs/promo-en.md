
**Text (first comment):**

```
I kept losing track of the open-source AI tools for reading and reviewing
academic literature — they're scattered across GitHub, range from 39k-star
frameworks to 20-star experiments, and the names tell you nothing about what
they actually do.

So I organized 70+ of them by *what you're trying to do*, in 11 categories:
all-in-one research agents/skills, deep research & auto-survey, autonomous
"idea → paper" systems, paper Q&A/RAG, PRISMA screening, MCP servers,
Zotero/Obsidian integrations, PDF→structured-data extraction, citation graphs,
API clients, and writing/peer-review assistants.

A few design choices that might be useful to others building lists like this:
- Every star count is verified via the GitHub API and auto-refreshed weekly by
  a GitHub Action, so the numbers don't rot.
- Links are checked in CI, so dead entries get caught.
- There's a 30-second "picker" and a decision table so you can jump straight
  from "I need to screen 3,000 abstracts" to the right tool.
- It's CC0, bilingual (EN/中文), and PRs are welcome.

Repo: https://github.com/brycewang-stanford/lit-review-agent-tools

Happy to hear what I'm missing — especially tools you've actually used in a
real review, not just starred.
```
